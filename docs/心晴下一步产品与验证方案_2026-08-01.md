# 心晴 MindPulse 下一步产品与验证方案

- 制定日期：2026-08-01
- 适用版本：当前 Web/iOS 原型及下一阶段校园试用版本
- 依据：`docs/竞品市场研究与创新策略报告_2026-07-31.md`、当前代码和已通过的规则/安全测试
- 截止约束：当前只剩 5 天
- 方案状态：5 天冲刺版

## 0. 先说结论

在只剩 5 天的情况下，不再扩展成“功能更多的心理健康 App”，而只把心晴最有机会占据的中间环节做成一个可演示、可答辩、可回归测试的闭环：

> 学生发现自己的状态不太对劲时，心晴帮助他看见是否偏离自己的节奏，说明判断依据和不确定性，给出当前安全的下一步，并在需要时把求助转成一段由本人控制的表达。

下一阶段的成功，不是新增多少页面，而是证明以下四件事：

1. 用户能在低负担记录后理解“系统为什么这样判断”。
2. 用户能区分“普通波动”“数据不足”和“优先求助”三种路径。
3. 高风险时任何普通行动入口都无法绕过 Safety Gate。
4. 用户能在不自动上报、不默认暴露原始记录的前提下，完成一段自然的求助表达。

## 1. 目标与非目标

### 1.1 5 天截止目标

交付并验证一个“个人节奏 + Safety Gate + Campus Warm Handoff”的最小产品闭环，并形成一套可以向评审展示的证据包。截止日前不追求生产级部署和长期用户研究。

### 1.2 明确不做

- 不做抑郁、焦虑或其他疾病诊断。
- 不把 RISE 包装成医疗量表、危机预测器或疗效指标。
- 不把心晴做成 AI 心理医生或开放式危机聊天机器人。
- 不自动联系辅导员、家人、老师、热线、警方或急救机构。
- 不向学校输出个人风险名单、班级排行、宿舍热力图或可反推个人的报表。
- 不在没有审核和治理能力前运营真实多人树洞、漂流瓶或危机社区。
- 不以连续打卡、徽章、排名或“越严重越付费”作为增长机制。

## 2. 当前基础与主要缺口

| 能力 | 当前已有基础 | 下一步要补的不是功能，而是 |
|---|---|---|
| Safety Gate | `evaluateState()` 已处理高风险、数据不足、Safety Hold、允许/阻断动作和 DecisionTrace | 全入口覆盖审计、调用层防绕过、更多边界文本回归测试、用户可见的决策解释 |
| 个人基线 | 已有个人基线、信号偏移、数据完整度、置信度 | 7/14 天窗口、特殊时期标记、缺失信号解释、避免一次异常重写基线 |
| 求助表达 | `HelpComposer` 已支持对象、需求、紧迫度、可编辑草稿和复制前预览 | 把分享字段明确建模，展示“会分享/不会分享”，补资源失效时的兜底路径 |
| 校园资源 | 已有地区、学校、心理中心、老师、热线、服务时间和核验状态 | 资源配置模板、核验记录、过期提醒、单校试点的责任边界 |
| 数据台账 | 已有本机优先、导出、删除和数据来源展示 | 生产版加密存储、设备丢失、备份恢复、密钥和删除验证；原型试用继续禁止明文云同步 |
| 行动反馈 | 已记录行动前后主观变化，并限制高风险学习 | 明确“个人反馈不是因果疗效”，增加完成难度和再次尝试意愿，避免反馈污染安全策略 |

## 3. 截止版本：5 天内只交付 P0 核心闭环

5 天内只做以下四件事：安全路径稳定、求助路径可用、分享边界可见、答辩证据完整。任何不直接服务这四件事的需求都延期。

### P0-1 Safety Gate 全入口审计

**交付物**

- 建立动作入口清单：首页主按钮、底部导航、陪伴页、自检、普通练习、任务完成、反馈学习、深链接和路由跳转。
- 建立三态决策矩阵：普通行动、高风险、数据不足。
- 将所有普通动作统一收敛到 `canStartAction` 或等价调用层，不只依赖页面跳转。
- 增加高风险文本回归集：直接表达、隐喻、否定语境、引用他人、多段文字、错别字和中英文混杂。
- 决策详情统一展示：使用了什么数据、缺了什么数据、为什么允许/阻断、策略版本和置信度。

**验收标准**

- 高风险状态的 `allowedActions` 永远只有 `help`。
- 数据不足状态的 `allowedActions` 永远只有 `checkin`。
- 高风险状态不能进入 companion、self-check、普通练习或反馈学习。
- 通过首页、导航、深链接和直接调用四类入口验证，绕过数为 0。
- 每个测试用例都有稳定的决策编号、风险模式、允许动作和阻断原因。

**建议涉及文件**

- `src/domain/evaluate-state.ts`
- `src/security/risk-gate.js`
- `src/app/routes.tsx`
- `src/app/store.ts`
- `tests/safety-gate-smoke.js`（扩展现有测试）
- `tests/safety-gate-matrix.js`（规划新增）

### P0-2 Campus Warm Handoff v1

**交付物**

- 保留朋友、老师/辅导员、家人三类对象。
- 保留“先听我说、陪我保持联系、陪我找支持”三类真实需求。
- 高风险默认使用“现在需要联系”，普通路径默认不强迫即时联系。
- 求助草稿默认不带原始备注、完整历史、匿名 ID、未选择的睡眠或步数。
- 增加分享收据：本次复制正文会包含什么、不会包含什么，状态摘要是否被勾选。
- 资源无效、未核验或超过 90 天时，显示核验提醒和人工确认路径，不直接把失效链接作为主要按钮。

**验收标准**

- 用户可以在 2 分钟内生成、编辑并复制一段求助草稿。
- 用户能明确指出至少两项不会被默认分享的内容。
- 系统不会自动打开链接、自动发送、自动上报或自动联系任何人。
- 高风险时求助入口优先可见，普通练习不抢占第一主按钮。
- 资源状态为 invalid 时不能生成看似可用的热线/校园链接按钮。

**建议涉及文件**

- `src/components/HelpComposer.tsx`
- `src/components/SafetyGate.tsx`
- `src/domain/types.ts`
- `src/domain/help-resources.ts`
- `src/features/settings/SettingsPage.tsx`
- `tests/help-warm-handoff-smoke.js`（规划新增）

### P0-3 Privacy Receipt v0（只做可见收据）

截止日前先把现有的“分享前确认”做成可演示、可核验的收据；不在这 5 天内扩展云同步、加密存储或复杂后台。

**建议记录的字段**

- `decisionId`：这段状态摘要对应哪次判断。
- `includedFields`：用户主动选择分享的字段。
- `excludedFields`：系统明确未带出的字段。
- `sourceTypes`：手动记录、设备数据、示例数据或混合来源。
- `userEdited`：草稿是否被用户修改。
- `copiedAt`：用户是否主动复制，原型中不保存草稿正文。

**验收标准**

- 用户在复制前能看到分享预览。
- 未勾选状态摘要时，正文不包含状态摘要。
- 原始备注和完整历史永远不会被默认加入草稿。
- 测试可证明复制动作发生前没有外部发送。

### P0-4 P0 验证包

形成以下四份内部材料：

1. Safety Gate 规则矩阵。
2. 求助草稿和资源核验测试清单。
3. 10 分钟产品演示脚本：普通波动、数据不足、高风险三条路径。
4. 一页式边界说明：不诊断、不自动上报、不证明疗效、本地优先不等于加密。

## 4. 截止日后 P1：31-60 天，用真实学生验证是否有用

### P1-1 匿名学生试用

建议邀请 10-20 名大学生，连续 3-5 天完成匿名试用。试用目标是验证理解度和表达成本，不是收集临床数据。

**试用任务**

1. 完成一次低负担状态记录，记录完成时间和主观负担。
2. 用自己的话解释 RISE/个人节奏依据。
3. 指出当前允许的动作和暂不建议的动作。
4. 比较普通波动、数据不足、高风险三个演示场景。
5. 生成发给朋友、老师或家人的求助草稿。
6. 指出哪些信息会离开本机，哪些信息不会被带出。

**试用安全要求**

- 试用前明确原型不是医疗服务，不提供危机处置。
- 试用数据与合成演示数据分开保存和标注。
- 不要求参与者输入真实危机经历或完整个人隐私。
- 参与者出现明确高风险表达时立即停止研究任务，按事先准备的人工转接流程处理。
- 试用结束后允许参与者一键删除本机记录。

### P1-2 专业审核

至少邀请 1-2 名心理中心老师、辅导员或相关专业人士审核：

- 危机词、否定语境和引用他人文本的处理。
- 普通波动是否被过度升级。
- “风险”“恢复指数”“偏离”是否造成诊断误解。
- 高风险页面是否具体、克制且不会延迟真实求助。
- 求助草稿是否自然、非命令式、非责备式。
- 校园资源缺失、过期、地区不匹配时的兜底文案。

### P1-3 Personal Rhythm 2.0

- 增加 7 天和 14 天个人观察窗口。
- 标记考试周、返乡、假期、疾病、重大事件等特殊时期；特殊时期不直接与普通周比较。
- 展示每个信号的样本数、缺失状态、当前值和置信度。
- 一次异常记录只产生“待观察偏移”，不自动重写个人基线。
- RISE 作为解释摘要，不作为首页唯一主指标。

### P1-4 P1 通过标准

以下是产品可用性门槛，不是临床有效性门槛：

| 指标 | 首轮建议门槛 |
|---|---:|
| 能正确区分普通波动、数据不足、高风险 | 至少 80% 参与者 |
| 能说出至少两条判断依据 | 至少 80% 参与者 |
| 能在 2 分钟内完成求助草稿 | 至少 70% 参与者 |
| 能正确识别分享/不分享字段 | 至少 80% 参与者 |
| 高风险测试用例进入普通行动 | 0 |
| 未经用户主动复制/发送的数据外发 | 0 |
| 试点启用资源中未核验的热线/校内链接 | 0 |

所有门槛应在专业审核后再调整，不能把这些数字写成疗效或风险识别准确率。

## 5. 截止日后 P2：61-90 天，形成可复制的校园版本

### P2-1 单校资源配置包

先支持一个学校或一个校区，不先建设全校监控后台。

**配置内容**

- 学校/校区名称和地区。
- 心理中心、热线、辅导员/老师入口。
- 服务时间、联系人类型和备用路径。
- 最近核验日期、核验人/责任角色和策略版本。
- 资源失效后的替代文案。

**边界**

- 学校只配置资源和文案，不默认读取学生原始日记。
- 学生记录不进入个人风险名单。
- 研究数据只能在明确授权、聚合、最小样本和不可反推的前提下使用。

### P2-2 安全与隐私生产化清单

在真实规模化使用前完成：

- IndexedDB/本地文件的加密方案和密钥生命周期。
- 设备丢失、浏览器清理、备份恢复和跨设备迁移测试。
- 导出文件的敏感数据提示和用户确认。
- 删除后无法恢复的验证，以及浏览器缓存/下载文件边界说明。
- 若未来启用云同步，默认只允许加密密文，且同步状态对用户可见。

### P2-3 证据包与答辩包

交付以下材料：

- 一张产品闭环图：记录 → 个人节奏 → Safety Gate → 下一步 → Warm Handoff。
- 一张规则矩阵和代表性测试结果。
- 一张隐私收据示例。
- 学生试用理解度、表达成本和资源可用性结果。
- 专业审核意见和已修订文案。
- 明确区分合成演示数据、匿名试用数据和公开资料。

## 6. 5 天执行排程

### 第 1 天：冻结范围并盘点风险入口

- 确认唯一主目标：“安全地走到下一步”。
- 暂停新增 AI 聊天、内容库、社区和打卡功能。
- 列出首页、导航、深链接、陪伴、自检、普通练习、任务完成和反馈学习的所有入口。
- 运行现有类型检查、规则测试和 Safety Gate 测试，记录当前基线。

### 第 2 天：修复 Safety Gate 和三态演示

- 完成普通波动、数据不足、高风险三态案例。
- 补齐高风险文本的直接表达、否定、引用、错别字和混合语言样本。
- 确保高风险只保留 `help`，数据不足只保留 `checkin`。
- 通过首页、导航、深链接和直接调用验证普通行动不能绕过 Gate。

### 第 3 天：完成 Warm Handoff 和分享收据

- 核验朋友、老师/辅导员、家人三类求助对象和三种支持需求。
- 确保高风险默认“现在需要联系”，普通路径不强迫即时联系。
- 确认正文默认不带原始备注、完整历史、匿名 ID 和未选择的信号。
- 确认复制前能看到会分享/不会分享，且系统不会自动发送或上报。

### 第 4 天：打磨演示和答辩证据

- 固定 10 分钟演示脚本：普通波动 → 数据不足 → 高风险求助。
- 准备一页规则矩阵、一页隐私收据、一页竞品差异化和一页边界说明。
- 用真实配置或明确标注的示例配置核验热线、校园链接、服务时间和备用联系人。
- 只修复会影响演示、理解度和安全边界的问题，不做无关重构。

### 第 5 天：全量回归、备份和冻结

- 跑完整类型、领域、Safety Gate、安全和 UI 烟测。
- 从空白档案重新走三条路径，确认演示数据和匿名记录没有混淆。
- 检查高风险页面、求助资源、复制预览、导出和删除边界。
- 备份当前可演示版本和答辩材料，冻结范围；所有未完成项进入“截止日后”清单。

|---|---|---|

## 8. 截止日后的决策门

### 继续投入的条件

- Safety Gate 全入口回归保持 0 绕过。
- 用户能理解三种状态和至少两条判断依据。
- 求助草稿确实降低第一次开口成本，且用户认可可编辑和最小披露设计。
- 至少一个学校/校区的资源可以持续核验和更新。
- 专业审核者认可产品边界和关键文案。

### 需要收缩或返工的信号

- 用户只记住分数，无法说出下一步和判断依据。
- 高风险页面仍让用户先做普通练习。
- 资源过期、链接失效或联系人不清楚。
- 用户误以为系统会自动报警、自动上报或能够诊断。
- 试用者需要输入大量隐私才能完成核心流程。

### 仍然不要做的扩张

- AI 心理治疗和开放式危机陪聊。
- 学校个人风险监控、排名和预警名单。
- 没有治理能力的真实匿名社区。
- 用“降低抑郁/焦虑”“预测危机”“证明疗效”等未经证据支持的宣传。

## 9. 对外定位口径

### 一句话

> 心晴 MindPulse 是面向大学生的端侧匿名早期觉察与求助桥梁：帮助你看见是否偏离自己的节奏，知道当前安全的下一步，并把求助说出口。

### 30 秒

> 情绪日记擅长记录，冥想应用擅长提供内容，AI 陪伴擅长对话，心理服务平台擅长连接真人。心晴把中间的一步做成核心：先判断数据是否足够，再对比个人节奏，由 Safety Gate 决定当前允许的行动；当用户需要支持时，心晴只生成由用户控制、最小披露的求助表达，不诊断、不自动上报，也不把普通建议用于高风险场景。
