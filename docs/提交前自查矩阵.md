## 2. 提交前命令

提交前主命令：

```bash
npm.cmd run preflight
```

`preflight` 覆盖：

| 命令 | 覆盖内容 |
|---|---|
| `npm run audit:copy` | 恐吓化、命令式、诊断化和即时改善承诺表达 |
| `npm run audit:self` | 必备文件、截图证据、A07/A08 待执行状态、禁用表达和规则边界用例 |
| `npm run audit:docx` | 正式 docx 材料口径：PPT、答辩、提交清单、测试报告、心理安全、算法说明和研究/审核模板 |
| `npm run demo:smoke` | 3 分钟演示路径：恢复指数、解释、日报/周报、干预、高风险求助、导出、规则证据 |
| `npm run verify` | 规则测试、合成演示数据分析、UI 冒烟测试 |

如果修改页面、风险词、求助页、设置页、截图采集脚本或展示材料中引用的截图，需要另外运行：

```bash
npm.cmd run capture:evidence
```
