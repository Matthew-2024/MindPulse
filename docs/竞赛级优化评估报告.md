## 二、优化方案与收益

| 问题 | 已落地改进 | 收益 |
|---|---|---|
| 规则重复 | 新增 `src/rules/signals.js`，统一情绪等级、分数上限、危机模式和字段读取 | 提升模块化与可维护性，减少规则分叉 |
| 测试数字不可信 | Web 规则实验室补齐 R01-R13，并按真实用例计算 15/15 | 现场演示更经得起追问 |
| 占位试用数据 | 设置页改为“验证证据板”，从本地记录即时计算样本数、平均 RISE、干预覆盖率、Safety Gate 触发数 | 避免数据伦理风险，同时增强展示效果 |
| 风险解释薄弱 | `assessRisk` 增加 `desc` 和 `evidence` 字段 | 风险判断更可解释，便于答辩引用 |
| 交付检查分散 | 新增 `npm run verify` 串联规则测试、合成分析、UI 冒烟 | 提升工程可信度和提交前稳定性 |
| iOS 版本口径落后 | SwiftUI 版同步 13 条规则用例、风险证据字段和验证证据板 | Web 与 iOS 双端演示口径一致 |

## 三、关键代码修改

### 1. 规则信号层统一

修改前：`recovery-score.js`、`risk-assessment.js`、`personalization.js` 各自维护情绪等级、字段读取和数值转换。

修改后：新增共享模块：

```js
// src/rules/signals.js
export const MOOD_LEVELS = {
  happy: 5,
  calm: 4,
  anxious: 3,
  sad: 2,
  tired: 2,
  angry: 2
};

export function sleepOf(record = {}) {
  return toNumber(record.sleepHours ?? record.sleep, 0);
}
```

收益：规则引擎更接近 Clean Architecture 的“核心领域层”，页面和测试只消费规则结果。

### 2. 风险分级证据增强

修改前：风险结果主要返回 `level/reason`。

修改后：返回可解释证据：

```js
return {
  level: "高风险",
  tag: "优先求助",
  reason: `文本中出现危机信号（${dangerResult.level}级）...`,
  desc: "文本中出现危机信号时，心晴会先停下普通自助建议...",
  evidence: [`Safety Gate: ${dangerResult.level}`, `pattern: ${dangerResult.matchedPattern}`],
  shouldRecommendSelfHelp: false
};
```

收益：答辩可明确说明“不是诊断，而是用于决定是否停止普通自助建议”。

### 3. 页面规则验证真实计数

修改前：

```js
var autoTotal = 15;
var autoPassed = passed + personalization.filter(function(x){ return x.pass; }).length + 5;
```

修改后：

```js
var autoTotal = results.length + personalization.length;
var autoPassed = passed + personalization.filter(function(x){ return x.pass; }).length;
```

收益：规则实验室显示的 15/15 来自真实用例，不是页面写死。

### 4. 证据板替代占位试用报告

修改前：设置页固定显示“16 人、72%、46%、4.1”，并标注为模拟占位。

修改后：从当前匿名档案即时计算：

```js
function validationReport(){
  var records = Array.isArray(S.recs) ? S.recs : [];
  var analyzed = records.map(function(record,index){
    var history = records.slice(0,index+1);
    return {
      score: rules().calculateRecoveryScore(record, record.completedInterventions || []).total,
      risk: rules().assessRisk(history).level
    };
  });
  ...
}
```

收益：展示更真实，且明确不把演示数据伪装成用户研究。

### 5. iOS SwiftUI 版同步强化

修改前：iOS 版规则实验室只有 8 条规则样例，设置页仍使用固定占位实验摘要，风险判断结果没有证据字段。

修改后：SwiftUI 版同步 Web 版竞赛口径：

```swift
struct RiskAssessment: Codable, Equatable {
    var level: RiskLevel
    var tag: String
    var reason: String
    var desc: String
    var evidence: [String]
    var shouldRecommendSelfHelp: Bool
}
```

收益：iOS 首页详情、设置页证据板和规则实验室均能展示同一套 RISE / Safety Gate / 个性化推荐验证链路。

## 四、创新点包装

1. MindPulse-RISE 可解释恢复指数  
项目不是简单情绪打卡，而是融合 Rhythm 节奏、Interaction 连接、Self-report 自评和 Engagement 干预反馈，形成可解释的端侧恢复指数。

2. Safety Gate 心理安全闸门  
系统将高风险识别作为普通推荐逻辑之上的安全边界，一旦触发危机信号，停止普通自助干预并优先连接可信任的人和专业资源。

3. 个人基线驱动的个体化判断  
项目不把用户和群体平均值比较，而是根据匿名档案近几天睡眠、活动、连接和情绪变化判断“是否偏离自己的正常节奏”。

4. 干预反馈自适应推荐  
系统记录用户完成干预后的恢复指数变化，下次优先推荐对当前匿名档案更有效的低负担行动，形成轻量个体化闭环。

5. 可复现评委验证模式  
设置页提供规则实验室和验证证据板，评委可以现场查看恢复指数、风险分级、推荐路径和 Safety Gate 的输出结果。
