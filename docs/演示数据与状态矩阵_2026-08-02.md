# 心晴 MindPulse 演示数据与状态矩阵

- 日期：2026-08-02
- 适用版本：React Web / 手机画布 Demo
- 目的：把示例记录、空白档案、匿名手动记录和本机漂流瓶分开，并让三态行为可以在答辩中复现。
- 证据边界：本文件记录当前代码和自动化测试能证明的行为，不代表临床有效性、真实多人社区或真实用户研究结果。

## 1. 数据模式

| `dataMode` | 进入方式 | 页面标签 | 可以说明什么 | 不能说明什么 |
|---|---|---|---|---|
| `synthetic-demo` | 首次打开或设置页恢复演示数据 | 示例记录 | 展示个人节奏、依据和普通波动路径 | 不是匿名试用数据，不是真实用户结果 |
| `empty` | 清理本机记录后重新打开 | 还没有记录 / 空白档案 | 展示数据不足门控和补充记录入口 | 不计算完整状态分，不给普通行动结论 |
| `real-trial` | 从空白档案或示例档案手动保存记录 | 匿名记录 / 本地记录 | 展示用户主动留下的本机记录和决策链 | 不代表真实研究样本或临床证据 |
| `public-reference` | 仅用于公开资料或规则展示的外部配置 | 公开资料 | 展示规则来源或公开参考 | 不应混入个人记录 |

手动记录从 `synthetic-demo` 或 `empty` 转为 `real-trial`。漂流瓶始终使用当前本机匿名档案编号关联，示例瓶是代码内固定内容，不写入用户自己的导出数据。

## 2. 固定 Fixture

### `NORMAL_DEMO`

- 准备：设置 → 恢复演示数据。
- 数据：7 条 `synthetic-demo` 记录，含情绪、睡眠、活动和连接感。
- 预期：进入个人节奏、依据、普通安全行动和本机演示海域。
- 关键标签：示例记录。

### `INSUFFICIENT_EMPTY`

- 准备：设置 → 删除本地记录，确认后重新打开首页。
- 数据：0 条记录；若要演示部分记录，只在 `/checkin` 填写情绪后保存。
- 预期：空白档案显示 `—`；部分记录只显示暂定参考指数和 `已收集 1/4 项`，完整状态分暂不计算。
- 允许：补充记录、查看为什么数据不足、设置和数据控制。
- 阻断：陪伴、漂流瓶、普通个性化行动。

### `HIGH_RISK_TEXT`

- 准备：使用固定合成文本 `我很绝望，想从这个世界上消失`，不要求参与者输入真实经历。
- 预期：只保留 `/help`，显示当前依据、资源核验状态、求助草稿和 Privacy Receipt。
- 阻断：陪伴、普通练习、自检、漂流瓶、反馈学习和绕过路由的直接调用。

## 3. 三态决策矩阵

| 状态 | `risk.mode` | `allowedActions` | 第一主按钮 | 普通动作 | 漂流瓶 |
|---|---|---|---|---|---|
| 普通波动 | `action` | 普通安全行动 | 开始第一步 | 允许，但仍经过 `canStartAction` | 允许本机 Demo |
| 数据不足 | `ask` | `checkin` | 补充一条记录 | 阻断，不输出确定建议 | 阻断并回到 `/checkin` |
| 高风险 | `help` | `help` | 打开求助入口 / 生成第一句话 | 阻断率 100% | 阻断并回到 `/help` |

“普通波动”不是健康结论；它只表示当前数据满足当前规则的行动门槛。高风险和数据不足都优先保护下一步，而不是显示一个看起来精确的数字。

## 4. 路由与入口行为

| 入口 | 普通波动 | 数据不足 | 高风险 |
|---|---|---|---|
| `/` | 显示当前状态、依据和第一步 | 显示还不够了解，主按钮为补充记录 | 重定向 `/help` |
| `/checkin` | 可记录 | 可记录 | 只有 `safetyReassessmentOpen` 时可进入，否则重定向 `/help` |
| `/insight` | 显示依据和完整状态分 | 可显示缺失信号与暂定参考，不安排普通行动 | 重定向 `/help` |
| `/companion` | 可进入陪伴流程 | 重定向 `/checkin` | 重定向 `/help` |
| `/help` | 可生成连接支持草稿 | 可查看连接入口 | 唯一普通主入口，显示 Safety Gate |
| `/settings` | 可导出、核验资源、删除本机数据 | 可导出和删除 | 由全局 Safety Gate 留在 `/help`；完成安全重新评估后再操作数据设置 |
| `/rules`、`/reports` | 可查看 | 可查看不确定性和空状态 | 重定向 `/help` |
| `/bottle` | 可进入本机 Demo | 重定向 `/checkin` | 重定向 `/help` |

入口覆盖四层：首页主按钮、底部导航、直接 URL、组件/调用层。`BottomNav` 对数据不足禁用陪伴，对高风险只保留求助；`BottlePage` 和 `canStartAction` 继续做第二次校验。

## 5. 决策收据字段

每个 `MindPulseDecision.trace` 至少包含：

`decisionId`、`reasonCodes`、`evidence`、`policyVersion`、`dataSource`、`confidence`、`allowedActions`、`blockedActions`。

参考指数只在 `ScoreResult` 中记录 `referenceScore`、`referenceRawTotal`、`referenceMax`、`referenceSignalCount` 和 `referenceSignalRequired`。空记录的 `referenceScore` 为 `null`，页面显示 `—`；部分记录只按已填写信号归一化，不把缺失项当作 0 分。

## 7. 演示禁区

- 不把 `synthetic-demo` 说成真实用户结果。
- 不把本机漂流瓶说成真实多人社区。
- 不把参考指数说成健康分数、诊断或危机预测。
- 不要求参与者输入真实危机经历；真实高风险表达出现时停止走查并人工转接。
