# 心晴 MindPulse 匿名试用执行包

本文档用于在 10-20 名大学生匿名试用前统一说明、记录口径和结果汇总方式。它不是用户研究结果报告，只有完成真实试用并回填数据后，才能把 A07 从“待补”改为“通过”。

## 1. 试用边界

| 项目 | 说明 |
|---|---|
| 试用目的 | 验证记录负担、恢复指数理解度、轻干预可执行性、求助表达有用度和隐私感受 |
| 试用人数 | 10-20 名大学生 |
| 试用周期 | 3-5 天 |
| 试用方式 | 使用 Web 原型或现场手机宽度预览，自愿记录状态和体验反馈 |
| 产品边界 | 心晴不做心理诊断、不替代咨询、不承诺改善症状 |
| 数据边界 | 只记录匿名反馈，不收集手机号、学号、定位、联系人、聊天记录或真实姓名 |
| 风险边界 | 若试用者表达强烈绝望、自伤、自杀等风险，立即停止普通试用反馈，优先提醒联系校内支持、老师、家人或热线 |

## 2. 试用前说明

可直接发给试用同学：

> 你好，我们正在测试一个面向大学生压力早期觉察的原型“心晴 MindPulse”。它不是心理诊断工具，也不替代专业咨询，只用于体验情绪记录、恢复指数解释、轻量行动建议和求助表达草稿。  
>  
> 本次试用自愿参加，可随时退出。我们不会收集手机号、学号、定位、联系人、聊天记录或真实姓名。你可以只反馈使用感受，不需要填写任何让你不舒服的内容。  
>  
> 如果你在试用过程中出现强烈绝望、自伤或自杀想法，请优先联系身边可信任的人、老师、校心理中心或当地紧急支持资源，不要把这个原型当作危机处理终点。

## 4. 量化指标

| 指标 | 计算方式 | 目标线 | 结果 |
|---|---|---:|---|
| 记录完成率 | 实际记录次数 / 预期记录次数 | 60% 以上 | 待回填 |
| 干预完成覆盖率 | 至少完成一次推荐行动的人数 / 试用人数 | 40% 以上 | 待回填 |
| 恢复指数理解度 | 能说出至少 2 个分数来源的人数 / 试用人数 | 70% 以上 | 待回填 |
| 求助表达有用度 | 1-5 分平均分 | 3.8 以上 | 待回填 |
| 隐私说明清晰度 | 1-5 分平均分 | 4.0 以上 | 待回填 |
| 继续使用意愿 | 1-5 分平均分 | 3.5 以上 | 待回填 |

## 5. 访谈问题

| 问题 | 记录要点 |
|---|---|
| 你愿意每天用 1 分钟记录状态吗？ | 记录负担、入口是否清楚 |
| 恢复指数的分数拆解能看懂吗？ | 用户能否说出情绪、睡眠、活动、社交、干预反馈 |
| 推荐的第一步是否真的能做？ | 是否低负担，是否有不适或压力 |
| 高风险时停止普通练习、进入求助入口是否合理？ | 是否理解 Safety Gate |
| 求助表达草稿像你会发出去的话吗？ | 语气是否自然、是否太重或太轻 |
| 哪些内容会让你担心隐私？ | 是否担心上传、身份、定位、联系人 |
| 哪些文案会让你更焦虑？ | 记录 A10 后续修改点 |

## 7. 回填自查清单规则

只有同时满足以下条件，才可把 A07 从“待补”改为“通过”或“基本通过”：

1. 有 10-20 名试用者的匿名编号和汇总数据。
2. 能区分真实匿名试用数据、合成演示数据和公开数据集参考。
3. 至少回填 3 条代表性反馈和对应整改动作。
4. 没有收集手机号、学号、定位、联系人、聊天记录或真实姓名。
5. 高风险反馈未继续走普通试用评价，而是优先引导求助资源。
