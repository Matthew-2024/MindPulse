# 本机数据删除前后键清单

- 日期：2026-08-02
- 目标：验证“删除本机记录”不仅清理状态记录，也清理当前匿名档案产生的漂流瓶、回应、隐藏和举报边界。

## 1. 删除前可能存在的键

| 类型 | 键/存储 | 内容 | 删除后预期 |
|---|---|---|---|
| 档案编号 | `mindpulseReactVaultId` | 当前本机匿名档案编号 | 保留，以便本机继续使用同一编号 |
| 清理标记 | `mindpulseReactVaultCleared` | 是否已经清理过 | 设置为 `1` |
| 主记录 | IndexedDB `mindpulse-local-vault` / `vault_records` / 当前 vault id | 记录、行动事件、判断收据、资源配置 | 当前 vault 记录不存在 |
| 漂流瓶 | `mindpulse:bottleSea` | 本机投放的漂流瓶数组 | 当前档案自己的瓶子移除；无其他瓶子时键移除 |
| 自有瓶回应 | `mindpulse:<vaultId>:bottleReplies` | 当前档案瓶子的可见匿名回应 | 移除 |
| 隐藏 | `mindpulse:<vaultId>:bottleHidden` | 本机隐藏的瓶子 ID | 移除 |
| 举报 | `mindpulse:<vaultId>:bottleReports` | 本机举报记录 | 移除 |
| 其他瓶主回应键 | `mindpulse:<otherOwnerId>:bottleReplies` | 当前档案作为 `senderId` 写出的回应 | 仅移除当前档案写出的回应，保留无关回应 |

固定示例瓶不写入 `mindpulse:bottleSea`，因此不是用户自己的数据，也不会进入导出。

## 2. 删除动作顺序

1. 用户确认“确定删除本机记录”。
2. `deleteVault(vaultId)` 删除 IndexedDB 当前档案。
3. `clearOwnData(vaultId)` 删除当前档案自己的漂流瓶相关键，并扫描 `*:bottleReplies` 清理当前档案作为发送者写出的回应。
4. 写入 `mindpulseReactVaultCleared=1`。
5. React 状态切换为空白档案，重新打开时显示“还没有记录”。

导出文件不会被自动删除，设置页明确写着“已经导出的文件不会自动删除”。

## 3. 验收断言

- `tests/bottle-repository-tests.js`：验证清理自有瓶子、隐藏、举报，以及当前档案写给示例瓶的回应。
- `tests/react-storage-smoke.js`：验证 IndexedDB vault 删除、清理标记和记录键。
- `tests/react-bottle-smoke.js`：浏览器级验证投放 → 回应 → 导出 → 删除 → 所有漂流瓶相关键清空 → 旧瓶子不可在应用内恢复。
