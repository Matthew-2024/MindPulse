# 心晴 MindPulse 专业审核执行包

本文档用于邀请心理老师、辅导员、校心理中心老师或心理健康课程教师审核心晴 MindPulse 的心理安全边界。它不是专业审核结论，只有完成真实审核并回填意见后，才能把 A08 从“待补”改为“通过”。

## 1. 审核目标

| 审核项 | 需要确认的问题 |
|---|---|
| 产品边界 | 是否清楚表达“不诊断、不治疗、不替代咨询、不作为危机干预终点” |
| Safety Gate | 高风险样本是否停止普通轻干预主路径，优先进入求助入口 |
| 风险词与误判 | 当前危机词、孤立表达、安全短语过滤是否合理 |
| 求助页面 | 热线、老师、家人、可信任成人、校内资源提示是否合适 |
| 轻自查文案 | PHQ/GAD/PSS 入口是否避免把分数说成诊断结果 |
| 推荐建议 | 呼吸、散步、记录、联系朋友等建议是否低负担、可退出、不承诺疗效 |
| 隐私伦理 | 是否避免收集手机号、学号、定位、联系人、聊天记录等非必要敏感信息 |

## 2. 发给老师的说明

可直接复制：

> 老师您好，我们正在准备“心晴 MindPulse”国赛作品，希望请您帮忙做一次心理安全与伦理边界审核。  
>  
> 这个作品定位为大学生压力早期觉察、轻量行动和求助表达的端侧辅助工具，不做心理诊断，不替代咨询，也不作为危机干预终点。我们希望重点请您看：高风险文案是否合适、Safety Gate 是否应更保守、求助入口是否充分、轻自查和恢复指数是否容易被误解为医学判断。  
>  
> 我们会把您的意见按 P0/P1/P2 归类，只记录审核建议和整改动作，不公开个人敏感信息。

## 4. 建议现场演示路径

1. 打开首页，说明恢复指数不是医学量表。
2. 展开“看依据”，展示分数拆解、个人基线和 Safety Gate 解释。
3. 进入轻自查，展示“分数提示”而非诊断标签。
4. 新增一条高风险备注，例如“我很绝望，想从这个世界上消失”。
5. 确认主按钮进入求助页，而不是呼吸、散步等普通练习。
6. 打开求助页，检查热线、老师/辅导员、家人/可信任成人和求助话术。
7. 打开设置页规则验证，确认 20/20 自动化规则测试通过。

## 6. 风险等级回填规则

| 等级 | 处理方式 |
|---|---|
| P0 | 可能造成心理安全、伦理或严重误导风险。先修复，再重新跑规则测试和 UI 冒烟测试 |
| P1 | 会影响评委信任、用户理解或证据真实性。提交前修复，并更新 README 或对应文档 |
| P2 | 表述不够精确、体验可优化、证据可增强。记录到国赛落地清单 |

## 8. 回填自查清单规则

只有同时满足以下条件，才可把 A08 从“待补”改为“通过”或“基本通过”：

1. 至少 1 名心理老师、辅导员、校心理中心老师或心理健康课程教师完成审核。
2. 有审核日期、审核者角色、审核材料版本和问题记录。
3. P0/P1 问题已完成整改或明确暂停提交。
4. 整改后重新运行 `npm.cmd run verify` 或至少运行 `node tests/run-rule-tests.js` 与 `node tests/ui-smoke.js`。
5. 审核意见没有被包装成“医学认证”或“临床有效性证明”。
