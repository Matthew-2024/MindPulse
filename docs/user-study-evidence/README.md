# A07 匿名试用证据台账

本目录用于保存 10-20 名大学生匿名试用完成后的真实证据。当前目录只是台账和回填规则，不代表已经完成真实用户研究。

## 1. 当前状态

| 项目 | 状态 |
|---|---|
| A07 自查状态 | 待执行 |
| 真实试用人数 | 待回填 |
| 有效反馈人数 | 待回填 |
| 试用周期 | 待回填 |
| 数据来源 | 待真实匿名试用，不使用合成演示数据替代 |
| 是否可写“已完成真实用户研究” | 否 |

## 2. 证据文件命名

完成真实试用后，把材料放在本目录下，并使用下面命名：

| 文件 | 内容 | 必填 |
|---|---|---|
| `trial-summary.md` | 试用时间、人数、周期、量化指标、代表性反馈和整改动作 | 是 |
| `participant-ledger.csv` | 匿名编号、试用天数、记录次数、是否完成行动、理解度、隐私反馈 | 是 |
| `feedback-quotes.md` | 去标识化代表性反馈，只保留匿名编号 | 是 |
| `consent-script.md` | 实际发给试用者的知情说明版本 | 是 |
| `risk-events.md` | 如出现高风险反馈，记录是否停止普通反馈并转向求助资源；没有则写“无” | 是 |

## 3. `participant-ledger.csv` 字段

```csv
anonymous_id,trial_days,record_count,completed_action,used_help_draft,understood_recovery_score,privacy_clear,withdrawn,notes
U01,,,,,,,,
```

不要填写手机号、学号、姓名、定位、联系人、聊天记录或可识别身份的信息。

## 4. A07 回填条件

只有同时满足以下条件，才可把 `docs/自我审查项目.md` 的 A07 从“待执行”改为“通过”或“基本通过”：

1. `trial-summary.md`、`participant-ledger.csv`、`feedback-quotes.md`、`consent-script.md` 和 `risk-events.md` 都已存在。
2. `participant-ledger.csv` 中有 10-20 个匿名编号，且不包含真实姓名、手机号、学号、定位、联系人或聊天记录。
3. `trial-summary.md` 明确写出试用时间、试用人数、有效反馈人数、试用周期和量化指标。
4. 代表性反馈至少 3 条，并且每条都去标识化。
5. 文档中明确区分真实匿名试用数据、合成演示数据和公开数据参考。
6. 如出现高风险反馈，`risk-events.md` 记录了停止普通试用评价并优先提醒求助资源。
7. 回填后重新运行 `npm.cmd run audit:self`，确认 A07 状态变更有真实证据支撑。

## 5. 禁止写法

| 禁止写法 | 原因 |
|---|---|
| 已完成真实用户研究 | 当前台账未回填前不能写 |
| 基于真实用户数据证明有效 | 匿名试用只能支持可用性和理解度反馈，不能证明医学有效性 |
| 合成演示数据来自真实用户 | 混淆数据来源 |
| 用户研究验证心理疾病识别准确 | 超出产品边界 |

## 6. 推荐回填摘要

完成后可在 `trial-summary.md` 开头使用：

```text
本轮匿名试用共邀请 X 名大学生，获得 Y 份有效反馈，周期为 Z 天。数据只包含去标识化体验反馈，不含手机号、学号、定位、联系人、聊天记录或真实姓名。本结果用于评估记录负担、恢复指数理解度、轻干预可执行性、求助表达有用度和隐私感受，不作为诊断、治疗或医学有效性证明。
```
