# Privacy Receipt 字段定义与导出示例

- 日期：2026-08-02
- 适用范围：Warm Handoff 求助草稿、React 本机 JSON 导出
- 核心原则：记录用户选择的字段和复制动作，不保存用户编辑后的正文，不自动发送、不自动联系、不自动上报。

## 1. `HelpDraftEvent` 字段

| 字段 | 类型 | 说明 | 是否含用户正文 |
|---|---|---|---|
| `type` | `"help-draft"` | 事件类型 | 否 |
| `decisionId` | `string` | 生成收据时对应的判断编号 | 否 |
| `target` | `friend \| teacher \| family` | 用户选择的对象 | 否 |
| `need` | `listen \| stay \| accompany` | 用户选择的支持需求 | 否 |
| `urgency` | `now \| later` | 用户选择的联系紧迫程度 | 否 |
| `copied` | `boolean` | 是否发生用户主动复制 | 否 |
| `includeStateSummary` | `boolean` | 是否主动勾选状态摘要 | 否 |
| `includedFields` | `string[]` | 本次预览允许带出的字段标签 | 否 |
| `excludedFields` | `string[]` | 本次明确排除的字段标签 | 否 |
| `sourceTypes` | `string[]` | 判断使用的来源类型，如 `manual`、`synthetic-demo` | 否 |
| `userEdited` | `boolean` | 用户是否编辑过草稿 | 否 |
| `copiedAt` | `string \| null` | 主动复制发生时间；未复制为 `null` | 否 |
| `createdAt` | `string` | 收据事件写入时间 | 否 |

固定排除字段包括：`original-note`、`full-history`、`anonymous-vault-id`、`unselected-sleep`、`unselected-steps`、`device-data`；未勾选状态摘要时还包括 `state-summary`。

## 2. 可带出与不会带出

### 会包含

- 用户自己编辑后的草稿正文，只存在于复制动作的瞬间，不写入 `HelpDraftEvent`。
- 用户主动选择的支持对象、支持需求和紧迫程度。
- 用户主动勾选的状态摘要；默认不勾选。

### 不会包含在默认草稿或收据中

- 原始危机文本或原始备注。
- 完整历史记录。
- 匿名档案编号。
- 未主动选择的睡眠、步数、设备信息。
- 任何自动发送、自动报警或自动上报结果。

## 3. 收据 JSON 示例

下面是脱敏的结构示例，不是任何真实用户记录：

```json
{
  "type": "help-draft",
  "decisionId": "decision-7c1f2a90",
  "target": "teacher",
  "need": "accompany",
  "urgency": "now",
  "copied": true,
  "includeStateSummary": false,
  "includedFields": [
    "user-edited-draft",
    "support-target",
    "support-need",
    "urgency"
  ],
  "excludedFields": [
    "original-note",
    "full-history",
    "anonymous-vault-id",
    "unselected-sleep",
    "unselected-steps",
    "device-data",

  "copiedAt": "2026-08-02T12:00:00.000Z",

```

## 4. 导出 JSON 最小示例

```json
{
  "version": "mindpulse-react-v2",
  "exportedAt": "2026-08-02T12:01:00.000Z",
  "vaultId": "vault_demo_only",
  "dataMode": "real-trial",
  "records": [],
  "interventionEvents": [],
  "decision": {
    "trace": {
      "decisionId": "decision-7c1f2a90",
      "policyVersion": "mindpulse-policy-2.0",
      "dataSource": "匿名记录",
      "confidence": "low"
    }
  },
  "dataLedger": {
    "cloudCopy": "off"
  },
  "privacyReceiptEvents": [
    {
      "type": "help-draft",
      "decisionId": "decision-7c1f2a90",
      "copied": true,
      "includedFields": ["user-edited-draft", "support-target", "support-need", "urgency"],
      "excludedFields": ["original-note", "full-history", "anonymous-vault-id"]
    }
  ],
  "bottles": [],
  "bottleReplies": [],
  "bottleVisibility": {
    "hiddenBottleIds": [],
    "reports": [],
    "scope": "只包含当前匿名档案自己的瓶子、可见回应和本机隐藏/举报记录；固定示例瓶不作为用户数据导出。"
  },
  "privacyBoundary": "导出包含本机记录、当前匿名档案自己的漂流瓶与结构化分享收据；云端同步关闭，不包含自动发送或明文云端副本。"
}
```

导出文件是用户主动下载的本地文件。删除应用内本机数据不会承诺自动删除已经导出的文件，设置页已明确提示这一点。

## 5. 验收证据

- `tests/help-warm-handoff-smoke.js`：生成、编辑、复制至少三条收据事件；复制前无外部请求；编辑后的正文不出现在事件；导出包含收据和漂流瓶边界。
- `tests/react-ui-smoke.js`：分享前确认、默认不含状态摘要、可编辑和复制。
- `tests/react-bottle-smoke.js`：漂流瓶导出包含当前档案瓶子和可见匿名回应，且不导出另一个档案的 `senderId`。
