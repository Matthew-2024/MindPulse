# A08 专业审核证据台账

本目录用于保存心理老师、辅导员、校心理中心老师或心理健康课程教师完成审核后的真实证据。当前目录只是台账和回填规则，不代表已经完成专业审核。

## 1. 当前状态

| 项目 | 状态 |
|---|---|
| A08 自查状态 | 待执行 |
| 审核人数 | 待回填 |
| 审核者角色 | 待回填 |
| 审核方式 | 待回填 |
| 审核材料版本 | 待回填 |
| 是否可写“已完成专业审核” | 否 |

## 2. 证据文件命名

完成真实审核后，把材料放在本目录下，并使用下面命名：

| 文件 | 内容 | 必填 |
|---|---|---|
| `review-summary.md` | 审核日期、审核者角色、审核方式、总体意见、P0/P1/P2 汇总 | 是 |
| `review-issues.csv` | 每条审核意见、风险等级、整改动作、完成状态 | 是 |
| `material-version.md` | 审核时对应的 README、Web 原型、规则测试和文档版本说明 | 是 |
| `fix-log.md` | 对审核意见的整改记录和复验命令输出摘要 | 是 |
| `permission-note.md` | 是否允许在答辩材料中匿名引用审核者角色和意见 | 是 |

## 3. `review-issues.csv` 字段

```csv
issue_id,review_area,reviewer_role,comment,risk_level,fix_action,fix_status,verification
E01,,,,,,,
```

建议只记录审核者角色，例如“校心理中心老师”“辅导员”“心理健康课程教师”。如需记录姓名或单位，必须获得允许，并避免公开个人联系方式。

## 4. A08 回填条件

只有同时满足以下条件，才可把 `docs/自我审查项目.md` 的 A08 从“待执行”改为“通过”或“基本通过”：

1. `review-summary.md`、`review-issues.csv`、`material-version.md`、`fix-log.md` 和 `permission-note.md` 都已存在。
2. 至少 1 名心理老师、辅导员、校心理中心老师或心理健康课程教师完成审核。
3. 审核材料版本明确，不把后续修改包装成审核时已存在。
4. 所有 P0/P1 意见已经完成整改，或明确暂停提交/演示。
5. 整改后重新运行 `npm.cmd run audit:copy`、`npm.cmd run audit:self` 和 `npm.cmd run verify`。
6. 审核意见只作为心理安全和伦理边界建议，不写成“医学认证”“临床验证”或“疗效证明”。

## 5. 禁止写法

| 禁止写法 | 原因 |
|---|---|
| 已完成专业审核 | 当前台账未回填前不能写 |
| 获得医学认证 | 专业审核不是医学认证 |
| 通过临床验证 | 当前项目没有临床验证流程 |
| 老师证明系统可以诊断 | 超出产品边界 |
| 专业审核证明疗效 | 审核只看安全边界、伦理和文案风险 |

## 6. 推荐回填摘要

完成后可在 `review-summary.md` 开头使用：

```text
本轮专业审核由 X 名具备心理健康教育或学生工作经验的老师完成，审核方式为 X，材料版本为 X。审核重点为产品边界、Safety Gate、高风险文案、求助入口、轻自查文案、轻干预建议和隐私伦理。审核意见仅用于改进心理安全与伦理边界，不代表医学认证、临床验证或疗效证明。
```
