# 心晴 MindPulse 8–10 分钟答辩演示脚本与证据索引

- 版本：2026-08-02
- 演示设备：手机画布 `487x872`
- 演示数据：通过设置页“答辩演示状态”一键切换普通波动、空白档案和高风险三种固定合成路径。
- 重要说明：不要把自动化 Smoke、合成数据或视觉截图描述成真实用户研究或临床证据。

## 1. 演示脚本

### 0:00–1:00：竞品空位

“市场上已经有很多产品负责记录、内容、AI 对话和真人连接。心晴不复制其中一个类别，而是处理用户发现状态不对之后的中间问题：我是否偏离了自己、现在能做什么、是否需要找人、应该怎么说。”

指出主线：低负担记录 → Personal Rhythm → Safety Gate → 下一步 → Warm Handoff。

### 1:00–3:00：普通波动

1. 从示例记录首页开始。
2. 说明当前状态、睡眠/活动/连接感和个人历史如何构成依据。
3. 点击“看依据”，展示 `R / S / E` 三条解释。
4. 展示普通路径允许的最小行动。
5. 明确：这是记录指数和规则解释，不是健康分数、诊断或疗效证明。

### 3:00–4:30：数据不足

1. 设置 → 答辩演示状态 → “切换到空白档案”。
2. 指出首页“当前状态：数据不足”“现在可以做：补充一条记录”。
3. 只填写一项信号并保存，指出 `暂定参考`、`已收集 1/4 项` 和 `完整状态分暂不计算`。
4. 点击首页漂流瓶入口，说明它回到补充记录；指出系统拒绝装作给出确定的普通建议。

### 4:30–6:30：高风险

1. 设置 → 答辩演示状态 → “切换到高风险演示”，使用固定合成文本，不要求任何人输入真实危机经历。
2. 展示普通行动暂停、求助入口打开和当前依据。
3. 展示热线/校园资源的核验状态；失效或未核验资源不渲染为可用主按钮。
4. 直接访问 `/companion` 或 `/bottle`，展示仍回到 `/help`。

### 6:30–8:00：Warm Handoff 与 Privacy Receipt

1. 选择朋友、老师或家人。
2. 选择“先听我说”“陪我保持联系”或“陪我找支持”。
3. 选择紧迫程度；高风险默认“现在需要联系”。
4. 编辑草稿，确认默认不包含状态摘要。
5. 展示“会包含 / 不会包含”收据。
6. 复制草稿，强调系统不会自动发送、自动报警或自动上报；事件只保留字段选择和复制时间，不保留编辑后的正文。

### 8:00–9:00：数据控制

1. 漂流瓶页面沿“投放 → 捞取 → 回应 → 导出或删除”提示完成本机闭环。
2. 导出 JSON，指出 `dataMode`、`privacyReceiptEvents`、`bottles`、`bottleReplies` 和 `bottleVisibility`。
3. 删除本机数据，确认 IndexedDB 和漂流瓶相关本机键清理，重新访问漂流瓶不能恢复旧内容。

### 9:00–10:00：明确暂缓项

“真实多人社区、校园个人风险监控、AI 治疗和生产级云同步没有被藏在 Demo 里。它们需要独立治理、专业审核和隐私设计，属于截止日后的决策门。”
