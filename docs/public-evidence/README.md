# 公开资料证据层

本目录记录心晴 MindPulse 复赛版使用的公开资料。它们只用于：

- 解释规则为什么采用“早期觉察、分层求助、人工连接优先”的边界；
- 给 Safety Gate、数据不足和证据分层提供可复核的设计依据；
- 区分公开资料、合成演示数据、匿名试用数据、专业审核和临床有效性证据。

它们不用于训练模型，也不等同于心理老师或辅导员的专业审核意见。当前产品没有把这些资料转化为诊断、治疗建议、危机预测或自动上报结论。

## 使用原则

1. NICE/WHO 的原则会以 `src/domain/policy-basis.ts` 中的结构化引用进入决策追踪。
2. 每条引用同时记录“支持的产品决策”和“不能推出的结论”。
3. 公开资料链接不会在离线演示启动时被请求；只有用户主动点击来源链接时才会离开本地页面。
4. `dataMode` 为 `synthetic-demo` 的记录只用于演示规则输出，不会被写成真实试用结果。
5. 公开资料不能替代 A08 专业审核；专业审核完成前，审核证据仍保持“待执行”。

## 证据边界

当前可以声称：

- 规则的安全边界、来源和版本是可追溯的；
- 产品将高风险路径优先连接到人工、专业和可信任支持；
- 产品不使用低、中、高风险标签单独预测未来自杀或重复自伤；
- 公开研究可以作为产品方向和设计问题的参考。

当前不能声称：

- 心晴已经完成临床验证、疗效验证或专业审核；
- 公开研究样本就是心晴用户，或公开数据训练了心晴；
- 规则可以替代临床评估、危机干预、医疗服务或学校处置流程；
- 一次记录中的分数变化证明了任何行动的因果效果。

完整来源、用途和限制见同目录的 `source-ledger.csv`。
