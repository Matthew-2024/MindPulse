# 心晴 MindPulse 3 分钟演示视频录制脚本

本文档用于录制国赛提交和现场演示前的 3 分钟以内视频。它只证明当前 Web 原型核心路径可稳定复现，不代表真实用户研究结果或专业审核意见。

## 1. 录制前检查

录制前先运行：

```bash
npm.cmd run audit:copy
npm.cmd run audit:self
npm.cmd run demo:smoke
npm.cmd run verify
```

如果页面、风险词、求助页、导出或规则实验室发生变化，重新运行：

```bash
npm.cmd run capture:evidence
```

## 2. 推荐录制路径

| 时间 | 操作 | 画面重点 | 旁白口径 |
|---|---|---|---|
| 0:00-0:20 | 进入匿名档案页，点击进入当前档案 | 不需要手机号、学号或实名信息 | 心晴采用端侧匿名档案，当前比赛版不上传个人身份信息 |
| 0:20-0:45 | 首页展示恢复指数、风险等级和 Safety Gate | 恢复指数、风险等级、第一步按钮 | 这个分数是状态观察指标，不是医学诊断 |
| 0:45-1:05 | 点击“看依据”与“完整详情” | 判断依据、个人基线、RISE 方法、分数拆解 | 每个核心输出都能看到依据，避免黑盒判断 |
| 1:05-1:25 | 点击“开始第一步”，展示呼吸练习 | 4-4-4-4 呼吸、低负担行动 | 普通波动时只给低负担、可退出行动，不承诺疗效 |
| 1:25-2:05 | 新增一条高风险记录 | 手动填写睡眠、步数、连接感和备注 | 高风险样本不会继续走普通自助建议 |
| 2:05-2:25 | 点击“打开求助入口”，展示求助页和话术草稿 | 热线、老师/辅导员、话术草稿 | Safety Gate 优先把用户转向可信任的人和专业资源 |
| 2:25-2:45 | 进入设置页，点击导出记录 | `mindpulse-records.json` 下载提示 | 数据可导出给自己复盘或咨询前整理，仍保持匿名档案口径 |
| 2:45-3:00 | 打开规则验证 | 自动化规则测试 20 / 20 | 这些测试证明当前透明规则链路可复现，不代表医学有效性 |

## 3. 高风险样本

录制时可使用下面样本，只用于演示 Safety Gate：

| 字段 | 值 |
|---|---|
| 情绪 | 低落 |
| 睡眠 | 少于 5 小时 |
| 精力 | 低 |
| 连接感 | 需要联系 |
| 实际睡眠 | 4.4 |
| 实际步数 | 1400 |
| 社交连接 | 9 |
| 备注 | 我很绝望，想从这个世界上消失 |

## 4. 禁止口径

| 不要说 | 改成 |
|---|---|
| 心晴能诊断抑郁或焦虑 | 心晴用于早期觉察和求助表达 |
| 恢复指数证明用户好转 | 恢复指数帮助观察状态变化 |
| 高风险时先做呼吸就好 | 高风险时优先求助，普通练习不作为主路径 |
| 这些截图是真实用户研究结果 | 这些截图是当前原型的可复现演示证据 |
| 已经完成专业审核 | 专业审核仍按执行包推进，完成后再回填 |

## 5. 录制后自查

录制完成后检查视频是否满足：

| 检查项 | 最低标准 |
|---|---|
| 产品边界 | 至少出现一次“不做心理诊断/不是诊断”的口径 |
| 数据边界 | 说明当前为匿名档案、演示数据或手动输入，不包装成真实用户研究 |
| 高风险流程 | 高风险记录的第一主按钮进入求助入口 |
| 解释性 | 展示恢复指数拆解、判断依据或 RISE 方法 |
| 隐私控制 | 展示 JSON 导出入口 |
| 规则证据 | 展示规则验证 20 / 20 |

视频通过后，再把文件名、录制日期和最终版本记录到 `docs/自我审查项目.md` 的自查记录中。
