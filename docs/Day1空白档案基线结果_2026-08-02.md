# Day 1 空白档案基线结果

- 日期：2026-08-02
- Fixture：`INSUFFICIENT_EMPTY`
- 执行方式：清理设置页本机记录后重新加载 React 应用；浏览器验证使用 `http://127.0.0.1:5181`。

## 1. 基线观察

| 检查项 | 预期 | 当前结果 |
|---|---|---|
| 首页档案标签 | 空白档案 / 还没有记录 | 通过：显示 `还没有记录` |
| 完整状态分 | 不计算 | 通过：显示 `—` 和 `完整状态分暂不计算` |
| 参考指数 | 无已填写信号时不可用 | 通过：`referenceScore=null`，页面显示 `还没有可计算信号` |
| 数据不足主按钮 | 补充一条记录 | 通过：主按钮进入 `/checkin` |
| 漂流瓶入口 | 不进入互动 Demo | 通过：入口显示“先补充记录”，直接 `/bottle` 回到 `/checkin` |
| 陪伴入口 | 不进入普通行动 | 通过：底部入口禁用，直接 `/companion` 回到 `/checkin` |
| 演示记录混用 | 不应发生 | 通过：清理标记保留，重新打开不恢复 `synthetic-demo` 历史 |

## 2. 部分记录补充观察

只选择“平稳”并保存一条手动记录后：

- `dataMode=real-trial`，页面标签为匿名/本地记录。
- 页面显示 `暂定参考`、`已收集 1/4 项`。
- 页面继续显示 `完整状态分暂不计算`。
- 参考指数只使用已填写的情绪信号，不把睡眠、活动和连接感当成 0 分。
