# 心晴 MindPulse 当前测试与自查报告

本文档记录当前版本可复现的自动化测试、自我审查护栏、合成演示数据分析和前端截图证据。它用于提交前审查，不等同真实用户研究或专业审核意见。

## 2. 当前通过命令

```bash
npm.cmd run preflight
```

当前 `npm.cmd run preflight` 包含：

```bash
npm run audit:copy
npm run audit:self
npm run audit:docx
npm run demo:smoke
npm run verify
```

页面或截图证据变化时，另外运行：

```bash
npm.cmd run audit:self
npm.cmd run audit:docx
npm.cmd run capture:evidence
npm.cmd run verify
```

当前 `npm.cmd run verify` 包含：

```bash
npm run test:rules
npm run analyze:synthetic
npm run test:ui
```

## 6. 提交前复验顺序

1. 修改风险词、求助页、推荐逻辑或页面文案后，先运行 `npm.cmd run preflight`。
2. 需要更新截图证据时，运行 `npm.cmd run capture:evidence`。
3. 录制演示视频前，运行 `npm.cmd run demo:smoke` 并按 `docs/演示视频录制脚本.md` 检查旁白口径。
4. 提交前运行 `npm.cmd run preflight`。
5. 如果 A07/A08 已有真实外部材料，先按对应 evidence README 补齐证据文件，再更新 `docs/自我审查项目.md`，不要提前把“待执行”改成“通过”。
