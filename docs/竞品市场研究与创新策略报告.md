# 心晴 MindPulse 竞品市场研究与创新策略报告

- 调研日期：2026-07-29
- 调研范围：英文与中文市场的公开产品官网、帮助/隐私页面，以及公开的数字心理健康评估资料
- 目标：识别 MindPulse 与成熟产品的重叠点，找到可解释、可验证、可持续的差异化方向
- 结论性质：产品事实来自公开页面；竞品未展示的能力只表述为“本次核对页面未见”，不表述为市场中绝对不存在

## 一、先给结论

### 1. 市场已经把“情绪记录”做成了成熟能力

本轮核对的产品大致分成五条路线：

| 路线 | 代表产品 | 用户主要购买的价值 |
|---|---|---|
| 记录与模式发现 | Daylio、Stoic、Bearable、MindDoc | 快速记录、趋势、相关性、长期回顾 |
| AI 情绪陪伴 | Wysa、Youper、Headspace Ebb、7 Cups Noni | 随时对话、反思、练习、转介 |
| 睡眠与放松内容 | Tide、Headspace、Stoic | 冥想、呼吸、睡眠声音、专注计时 |
| 同伴与专业服务 | 7 Cups、壹心理、简单心理 | 倾听、社区、心理咨询、课程和评估 |
| 校园早期觉察与求助转接 | 本次核对的公开产品中没有看到与 MindPulse 完全同构的产品 | 这是 MindPulse 可以主动占据的细分位置 |

### 2. MindPulse 不应把“AI 聊天、音频内容、打卡、情绪日记”作为主创新

这些能力已经被不同产品覆盖：

- Daylio 把两步情绪和活动记录、统计、相关性、目标、提醒、导出和本地隐私做得很完整。
- Stoic 把引导式日记、每日反思、趋势、呼吸/冥想、提醒和习惯激励组合成了成熟的自我照顾产品。
- Bearable 把症状、情绪、习惯、相关性和报告做成了更广义的健康观察工具。
- Wysa、Youper、Headspace 和 7 Cups 已经占据了 AI 对话、练习、危机提示或人工支持的不同位置。
- Tide、Headspace 等产品在睡眠、冥想、呼吸和专注内容上有明显的内容规模优势。

### 3. 最值得坚持的定位是“安全决策与求助转接层”

MindPulse 的真正机会不是再做一个更会聊天的 App，而是把下面这条链路做成产品核心：

> 看见自己偏离平时节奏的变化 -> 解释为什么这样判断 -> 判断当前哪些行动可以做、哪些不能做 -> 在需要时把状态翻译成一段用户愿意发给真实他人的话。

这个定位可以概括为：

> 面向大学生的端侧匿名早期状态观察与安全求助转接工具。

### 4. 单点功能不构成独家创新，组合机制才有机会形成壁垒

“Safety Gate”单点并非市场上完全没有先例。Youper 已公开说明危机文本识别、危机资源转介和自伤内容防护；Wysa 也公开强调危机边界、人工参与和可解释支持。隐私也不是单点空白，Daylio 和 Stoic 都强调设备端/私密存储，Bearable 强调加密、导出和删除。

MindPulse 应该主张的是以下组合，而不是“第一个有安全闸门的产品”：

1. 个人基线，而不是对用户贴一个群体化的心理分数。
2. 情绪、睡眠、活动、连接感等低敏感度自报信号的联合观察。
3. 数据不足时主动收敛，不装作已经了解用户。
4. 用户可见的 Reason Code、证据、允许动作、阻断动作、数据来源和置信度。
5. 高风险时由策略层强制阻断普通轻干预，而不是只在页面底部放免责声明。
6. 把“我需要帮助”转换成可编辑、由用户主动复制或发送的求助草稿。
7. 面向校园情境配置朋友、老师/辅导员、家人和校内资源的转接路径。

在本次核对的官方产品页面中，没有看到与上述粒度相同的完整组合。这是“公开页面证据下的差异化假设”，还需要用户试用和专业审核验证，不能直接称为行业空白或临床创新。

## 二、MindPulse 当前产品基线

### 1. 当前已经具备的能力

依据当前 README、领域策略和页面组件，MindPulse 已经具备：

| 能力 | 当前实现口径 | 竞争意义 |
|---|---|---|
| 低负担记录 | 情绪、睡眠、精力、步数、连接意愿和备注；一天可多次记录 | 与 Daylio、Stoic 等存在直接重叠，不宜单独宣传 |
| RISE 恢复指数 | 分数拆解为情绪、睡眠、活动、社交连接和干预反馈 | 具备多信号解释能力，但必须强调不是医学量表 |
| 个人基线 | 根据当前匿名档案历史记录判断是否偏离自己的节奏 | 比“今天得了几分”更接近产品核心差异 |
| 风险分级 | 稳定观察、普通波动、中度关注、高风险 | 为下一步行动服务，不用于诊断 |
| Safety Gate | 高风险只允许求助；数据不足只允许补充记录；普通行动不能绕过领域策略 | 有机会成为系统级差异化，但需继续扩充测试集 |
| 自适应轻干预 | 记录呼吸、散步、专注、睡前放松、联系朋友等行动及完成反馈 | 重点应从“推荐很多动作”转向“在安全边界内学习什么对这个人有帮助” |
| 决策追踪 | Reason Code、决策编号、证据、允许/阻断动作、策略版本、数据来源、置信度 | 是当前最不容易被普通日记产品直接替代的层 |
| 求助表达 | 面向朋友、老师/辅导员、家人生成可编辑话术；正文不主动离开本机 | 把觉察连接到真实支持，是重要差异点 |
| 日报/周报 | 本地时间线、趋势、低睡眠日、Safety Gate 触发和干预覆盖 | 与追踪类产品重叠，但可与个人基线和决策解释形成闭环 |
| 隐私控制 | 匿名档案、本地优先、JSON 导出、本地删除 | 需要注意：当前原型使用浏览器本地存储，不等于生产级加密存储 |
| 漂流瓶 | 当前为本机演示海域，不代表已上线多用户社区 | 不应拿它与 7 Cups 的真实社区规模比较 |

### 2. 当前不能过度宣称的内容

- RISE 是状态观察指标，不是抑郁、焦虑或其他疾病的诊断结果。
- 规则测试通过只证明规则可复现，不证明心理疾病识别准确，也不证明疗效。
- 合成演示数据不是用户研究；StudentLife 等公开资料不是本校用户数据。
- A07 匿名试用和 A08 专业审核仍应按已有执行包完成后再写成结果。
- 本地优先不等于“绝对安全”。正式产品仍需补充加密存储、密钥管理、备份恢复和设备丢失场景设计。

## 三、调研方法与证据边界

### 1. 证据等级

| 等级 | 使用方式 |
|---|---|
| A：官方产品页 | 只记录产品自己公开展示的定位、功能、免责声明和隐私承诺 |
| B：专业组织/公开研究 | 用于说明数字心理健康产品需要关注隐私、证据、风险、适配性和 AI 边界 |
| C：产品推断 | 只用于提出机会点；必须写明是基于公开页面的观察，不当作竞品的完整能力清单 |

### 2. 重要限制

- 本报告不是应用商店实机评测，也没有购买付费功能，因此无法判断所有竞品的真实交互深度。
- 产品页面会更新，功能和隐私政策可能随版本变化；结论以 2026-07-29 访问到的公开内容为准。
- 企业自述的用户数、覆盖量、评分、论文数量和“有效”表述没有被当成市场份额或疗效证据。
- Finch、Reflectly、Calm 等候选产品保留在后续观察名单中，本轮没有把无法稳定核对的页面内容写进核心事实矩阵。

## 四、核心竞品逐项分析

### 1. Daylio：记录和统计的成熟基准

官方页面明确展示：两步选择情绪和活动、文字/照片/语音记录、列表和日历、趋势图、相关性分析、目标、习惯、提醒、PDF/CSV 导出，以及应用私有目录存储和“不把条目发送到服务器”的隐私表述。

- 与 MindPulse 相似：低负担情绪记录、活动标签、趋势回顾、目标、提醒、导出和隐私控制。
- MindPulse 不应硬拼的地方：记录速度、统计数量、图表成熟度和习惯打卡。
- MindPulse 可以拉开的地方：Daylio 的公开页面重点是“记录后看见模式”，没有展示与 MindPulse 同粒度的风险策略、允许/阻断动作、数据不足收敛和求助话术闭环。
- 战略含义：Daylio 是“情绪日记”的对标基线，不是 MindPulse 的主战场。

来源：<https://daylio.net/>；隐私页：<https://daylio.net/faq/privacy-policy/>

### 2. Stoic：反思、内容和习惯养成的成熟基准

官方页面明确展示：每日反思、引导式日记、专家/治疗师启发的提示、趋势追踪、冥想和呼吸练习、提醒、连续记录、徽章、事件活动、设备端私密存储和跨设备同步。页面还展示了 AI 个性化日记的定位。

- 与 MindPulse 相似：每日 check-in、日记、趋势、低负担练习、提醒和隐私叙事。
- MindPulse 不应硬拼的地方：提示内容数量、情绪陪伴感、习惯激励和视觉完成度。
- MindPulse 可以拉开的地方：把“现在写什么/做什么”升级为“当前状态允许做什么”；让用户看见依据、置信度和被阻断的动作；高风险时让求助路径优先于普通练习。
- 战略含义：Stoic 证明“反思体验”可以做得很强，MindPulse 应补的是安全决策和真实求助转接，而不是复制更多提示卡片。

来源：<https://www.getstoic.com/>；页面隐私链接：<https://www.getstoic.com/privacy-policy>

### 3. Bearable：多因素相关性和健康报告的成熟基准

官方页面明确展示：症状和情绪追踪、习惯记录、睡眠/压力/焦虑/疲劳/疼痛等多维观察、相关性、模式、周/月趋势和 30 多种报告；页面还强调不出售数据、加密、可随时导出和删除。

- 与 MindPulse 相似：多信号、相关性、报告、长期观察、隐私控制。
- MindPulse 不应宣称的差异：不能说“只有我们能融合睡眠、活动、情绪”；Bearable 已经证明广义多因素健康追踪是成熟方向。
- MindPulse 可以拉开的地方：把相关性结果限制在个人基线和早期行动建议内，不把图表直接包装成疾病判断；进一步把每次建议的允许/阻断、数据来源和置信度透明化。
- 战略含义：Bearable 是 MindPulse 在“多信号观察”上的重要提醒，个人基线和安全行动层必须做得足够具体，否则会被归入普通健康追踪器。

来源：<https://bearable.app/>

### 4. MindDoc：个性化问答、模式识别和临床路径的成熟基准

官方页面明确展示：每天最多三次问题、根据回答个性化推荐音频课程和资源、图形化模式、定期反馈、70 多个课程和练习，并同时覆盖预防、治疗支持和持续照护。页面称其 Companion App 为欧盟 MDR I 类医疗器械，并提到超过 1000 名参与者的临床研究。

- 与 MindPulse 相似：重复 check-in、早期发现、模式反馈、个性化练习和长期记录。
- MindPulse 可以保持的边界：MindDoc 的官方定位已经进入医疗器械/治疗支持语境，MindPulse 则应明确定位为非诊断的大学生早期觉察和求助桥梁。
- MindPulse 可以拉开的地方：低数据量时不强行给出结论；强调“偏离自己的节奏”而不是症状标签；把反馈直接连接到校园可信任成人和专业资源。
- 战略含义：如果未来要做医疗或临床路径，证据、监管和专业团队要求会显著提高；当前不宜跟随 MindDoc 的医疗化表达。

来源：<https://minddoc.com/us/en/>

### 5. Wysa：安全型 AI 支持和机构服务的成熟基准

官方页面明确展示：匿名、随时可用、证据支持的 AI 支持、引导式转介、治疗间支持、人工参与、组织和医疗系统部署，以及危机免责声明。页面还明确表示 Wysa 不用于自杀、伤害自己等危机或医疗紧急情况，并称 AI 不会自行做决定。

- 与 MindPulse 相似：早期支持、匿名叙事、安全边界、转介和非诊断定位。
- MindPulse 不应硬拼的地方：AI 对话自然度、内容库、机构部署和专业服务网络。
- MindPulse 可以拉开的地方：不依赖生成式对话来承担判断；把安全策略前置到领域层，向用户展示固定的 Reason Code、证据、允许/阻断动作和策略版本；在端侧保留记录和求助草稿。
- 战略含义：Wysa 说明“安全”已经是 AI 心理产品的竞争语言，MindPulse 必须拿可运行规则、回归测试和审计轨迹证明，而不是只说安全。

来源：<https://www.wysa.com/>

### 6. Youper：AI 情绪跟踪与危机防护的直接对标

官方页面明确展示：AI 情绪健康聊天、心情追踪、反思和日记；同时公开了自伤/自杀表达的检测、危机资源转介、内容防护、系统不完美的限制说明、AI 身份披露和 18 岁以上年龄限制。

- 与 MindPulse 相似：情绪追踪、反思、安全优先、危机转介和明确的非医疗边界。
- MindPulse 不应宣称的差异：不能说“只有 MindPulse 有危机识别或求助入口”。
- MindPulse 可以拉开的地方：用确定性策略保证高风险时普通行动在调用层也被阻断；同时把睡眠、活动、连接感、个人基线和数据完整度纳入行动决策，而不把产品中心放在 AI 对话。
- 战略含义：Safety Gate 要从“页面上的安全说明”继续做成“系统不能绕过的政策执行层”，这才是可演示的工程差异。

来源：<https://www.youper.ai/>

### 7. Headspace：内容、AI 陪伴和专业服务的综合平台

官方页面明确展示：引导式冥想、睡眠资源、专家课程、随时练习、AI companion Ebb、在线心理咨询和面向组织的服务。

- 与 MindPulse 相似：状态相关内容推荐、呼吸/睡眠/压力练习和 AI 陪伴。
- MindPulse 不应硬拼的地方：内容库、品牌、专家课程、治疗服务和组织渠道。
- MindPulse 可以拉开的地方：Headspace 的核心是“给你内容和支持”，MindPulse 的核心可以是“在当前数据和风险边界下，先决定是否应该给普通行动”。
- 战略含义：MindPulse 未来可将 Tide/Headspace 类内容视为可插拔的干预资源，而不是自己承担内容规模竞争。

来源：<https://www.headspace.com/>

### 8. Tide：睡眠、专注、冥想和呼吸的中文场景基准

官方页面明确展示：睡眠与小憩、自然声音、轻唤醒闹钟、冥想课程、呼吸、专注计时器、番茄工作法和每日灵感。

- 与 MindPulse 相似：睡眠、呼吸、专注和低负担行动。
- MindPulse 不应硬拼的地方：声音内容、审美、计时体验和使用习惯。
- MindPulse 可以拉开的地方：Tide 负责提供一个练习或声音场景，MindPulse 负责判断当前是否适合普通自助行动，并记录行动后的主观变化。
- 战略含义：把放松音频作为“被策略允许的行动资源”，会比把音频当成产品主创新更稳妥。

来源：<https://tide.fm/>

### 9. 7 Cups：真人倾听、社区、AI 和咨询服务的综合基准

官方页面明确展示：免费匿名倾听、24/7 在线聊天、社区和支持小组、成长路径、自助指南、AI counselor Noni、青少年社区以及付费心理咨询。

- 与 MindPulse 相似：连接感、真实他人、求助、轻练习和匿名支持。
- MindPulse 不应硬拼的地方：真人网络、社区活跃度、咨询师目录和持续对话。
- MindPulse 可以拉开的地方：7 Cups 更像“进入支持网络”，MindPulse 可以专注于“什么时候值得进入网络、怎样用最少暴露的信息开口、怎样把状态说清楚”。
- 战略含义：漂流瓶和同伴支持是高风险业务，当前本机演示必须保持边界；真正上线前要单独建立内容审核、举报、未成年人保护、危机升级和隐私治理。

来源：<https://www.7cups.com/>

### 10. 壹心理：中文心理内容、评估、倾诉和咨询平台

官方页面展示：心理科普与问答、专业心理咨询、即时倾诉、心理测试、课程、冥想相关内容以及咨询师服务。

- 与 MindPulse 相似：中文心理教育、情绪表达、求助、评估和专业资源连接。
- MindPulse 不应硬拼的地方：专家数量、内容规模、咨询服务和平台运营。
- MindPulse 可以拉开的地方：把校园学生在求助前的状态观察、个人基线、数据来源、行动门控和可编辑求助草稿做成一个更窄、更明确的前置层。
- 战略含义：壹心理和类似平台更适合作为资源生态或转介目标，而不是直接复制其内容/咨询平台模式。

来源：<https://www.xinli001.com/>

### 11. 简单心理：专业服务、评估、AI 助理和热线的中文服务基准

官方页面展示：心理咨询、心理课程、心理健康报告、AI 咨询助理、心理评估、免费热线、精神科顾问和专业团队服务。

- 与 MindPulse 相似：评估、AI 陪伴、心理服务发现和求助转接。

## 六、真正的创新空白在哪里

### 空白一：从“我现在怎么样”到“我现在安全地先做什么”

大多数记录产品的终点是图表、相关性或反思；内容产品的终点是播放一个练习；AI 产品的终点是继续对话。MindPulse 可以把中间缺失的决策层做成核心：

```text
数据完整度 -> 风险闸门 -> 个人基线偏移 -> 允许的行动 -> 行动反馈 -> 下一次个性化
```

这条链路的创新点不是“推荐呼吸”，而是：

- 高风险时，普通呼吸、散步、专注等不再是主路径。
- 数据不足时，不装作已经理解用户，而是先补一条记录。
- 推荐不是无条件的，而是带有允许和阻断规则。
- 每次判断都能回答“为什么”“依据是什么”“数据来自哪里”“可靠度如何”。

### 空白二：从群体化分数到 N-of-1 的个人节奏

市场上已经有趋势、相关性和个性化反馈，但“个人基线”仍然可以成为 MindPulse 的清晰叙事：

- 不问“你比别人差多少”，先问“你是否偏离了自己的正常节奏”。
- 不把一次低落直接当成问题，观察连续性、强度、变化速度和信号缺失。
- 不把 RISE 写成医学判断，明确它是可解释的个人状态观察指标。
- 允许用户标记考试周、搬宿舍、旅行、疾病等特殊时期，避免基线被异常事件污染。

### 空白三：从“提供资源”到“降低第一次求助的表达成本”

7 Cups、壹心理、简单心理等产品已经提供了人、社区、咨询或热线。MindPulse 的差异不应是再建一个咨询平台，而是把“我不知道怎么开口”解决掉：

- 先生成状态摘要，而不是直接暴露全部日记。
- 让用户选择对象：朋友、老师/辅导员、家人或专业资源。
- 让用户选择需要的支持：先听我说、陪我保持联系、陪我找支持。
- 让用户选择紧迫程度，并可改成自己的语气。
- 系统不自动上报、不自动发送，只有用户主动复制或发送时信息才离开本机。

### 空白四：把隐私从“声明”升级成“可证明的控制权”

“我们重视隐私”已经是多个产品的公开表述。MindPulse 要做得更具体：

- 每条数据标注来源：用户自报、手动输入、历史基线、行动反馈。
- 每次结论展示使用了什么，没有使用什么。
- 分享前默认生成最小必要摘要，不默认带出原始备注。
- 用户可以预览、编辑、撤销和删除分享包。
- 分享包可带有效期和目的，例如“只用于本次和辅导员沟通”。
- 生产版使用加密存储和平台安全存储；原型阶段不把 localStorage 说成加密保险箱。

### 空白五：面向校园的具体情境，而不是泛化的“所有人心理健康”

在本次核对的产品首页中，主流产品大多面向广义用户、患者、员工、家庭或社区。MindPulse 可以围绕大学生的真实节点建立场景壁垒：

- 考试周和连续熬夜。
- 宿舍冲突、社团/小组合作和人际疏离。
- 毕业、升学、就业和实习压力。
- 不知道该找朋友、辅导员、心理中心还是家人。
- 担心留下记录、担心被评价，所以迟迟不愿求助。

校园场景不是换几张插画，而是要有可配置资源、校园话术、时间节点和真实转接路径。

## 七、创新优先级与落地方案

### P0：安全到行动的策略引擎

**目标**：让 MindPulse 的核心价值从“会分析”变成“在边界内决定下一步”。

**当前已有**：`decision-policy.js` 已有数据不足、高风险、普通波动、中度关注和稳定路径，并能生成 Reason Code、允许/阻断动作、证据、版本、来源和置信度。

**建议继续做**：

1. 把策略结果统一呈现为三句话：为什么这样判断、现在可以先做什么、暂时不建议做什么。
2. 对所有普通行动入口调用统一的 `assertActionAllowed`，避免页面按钮绕过 Safety Gate。
3. 建立风险词、否定语境、隐喻、错别字和多轮表达的测试集；单独记录误触发和漏触发。
4. 对数据不足、单次波动、连续波动和高风险分别设计不同的帮助文案。
5. 所有策略结果带策略版本和测试用例编号，方便答辩、专业审核和后续回归。

**建议验证指标**：

- 提议目标，不是当前结果：高风险回归用例中普通行动阻断率 100%。
- 数据不足回归用例中不输出未经依据的个性化结论。
- 参与者能够用自己的话复述系统为什么推荐或阻断某个行动。
- 专业审核者能定位每条高风险文案和路径的依据、边界与剩余风险。

**差异化价值**：这是工程机制和产品体验的结合，普通日记、音频或聊天功能较难直接替代。

### P0：校园 Warm Handoff 求助桥

**目标**：把“我知道自己不太对劲”转成“我现在能向谁开口”。

**建议产品形态**：

- 可配置校内心理中心、辅导员值班渠道、学校热线、当地公共热线和紧急服务。
- 每个资源显示服务对象、时间、地区、适用场景、最近核验时间和来源。
- 生成“最小必要分享包”：时间范围、用户选择的状态摘要、关键趋势、当前需要的支持和资源入口；默认不带出原始日记。
- 支持朋友、老师/辅导员、家人三类对象；允许用户编辑，不自动发送。
- 高风险时把“现在需要联系”置于普通轻干预之前；同时明确这不是自动报警或危机干预替代品。

**建议验证指标**：

- 用户能否在 60 秒内选出一个可信任对象并完成话术修改。
- 用户是否知道哪些内容会被分享、哪些仍留在本机。
- 用户是否理解系统没有替他发送或自动上报。
- 资源链接有效率、地区匹配率和过期资源发现率。

**差异化价值**：7 Cups、壹心理和简单心理解决“有人可以提供支持”，MindPulse 解决“学生如何从沉默走到第一次表达”。

### P1：个人节奏和基线升级

**目标**：让 RISE 从一个数字升级为可理解的 N-of-1 观察工具。

**建议产品形态**：

- 基线建立状态明确显示，不足时不显示过度精确的偏移。
- 支持 7 天/14 天等个人观察窗口，并说明记录数量、缺失信号和异常日。
- 把“偏离自己”与“风险信号”分开显示，避免用户把偏离等同于危险。
- 提供“这段时间是否为特殊时期”的用户标记。
- 用自然语言显示变化，例如“睡眠比你最近常态少约 2 小时”，而不是只给红色分数。

**差异化价值**：Daylio、Bearable、MindDoc 已经覆盖趋势、相关性和个性化反馈；MindPulse 需要把“个人基线如何影响行动门控”讲清楚，才不是换名的趋势图。

### P1：隐私证明和最小披露分享

**目标**：把本地优先从技术实现变成用户可以检查的权利。

**建议产品形态**：

- “本次判断用了哪些数据”与“没有读取哪些数据”清单。
- 分享包预览、字段开关、一次性导出、删除和有效期。
- 原始备注默认不出现在分享包中，除非用户明确选择。
- 生产版加入加密数据库、设备安全存储、备份加密和恢复密钥流程。
- 将匿名 ID、档案切换和数据删除的状态写入审计日志，但不记录原始心理文本到云端。

**差异化价值**：隐私本身不是空白；“隐私 + 数据来源 + 最小披露 + 用户可见决策依据”才是更完整的产品承诺。

### P2：基于反馈的个体化微行动

**目标**：从“推荐动作”进入“记录这个人对动作的主观响应”。

**建议产品形态**：

- 记录行动前后用户自评的变化、完成难度和是否愿意再次尝试。
- 只说“对你最近几次记录可能更合适”，不说“证明有效”或“治疗有效”。
- 让用户知道推荐来自自己的历史反馈，而不是群体模型的黑盒结论。
- 在高风险和数据不足路径上禁止用反馈学习绕过 Safety Gate。

**差异化价值**：内容产品提供固定内容，MindPulse 可以提供受安全边界约束的个人行动记忆。

### 暂缓：校园群体压力热力图

它看起来有展示价值，但对隐私和治理的风险最高。除非有明确的学校授权、最小样本门槛、差分隐私/聚合规则、用户知情同意和结果不可反推个人的保证，否则不建议把个人记录汇总成班级、宿舍或学院排名。当前阶段先把个人闭环和求助转接做好。

## 八、建议的产品定位与答辩口径

### 产品一句话

> MindPulse 不是心理咨询师，也不是另一个 AI 聊天机器人；它是面向大学生的端侧匿名早期觉察与求助桥梁，帮助用户看见偏离自己节奏的变化，知道当前安全的下一步，并把求助说出口。

### 30 秒差异化表达

> 市面上的情绪日记擅长记录，冥想 App 擅长提供内容，AI 陪伴擅长对话，心理服务平台擅长连接专业人员。MindPulse 把它们之间缺少的一层做成核心：先用个人基线和多信号观察理解“我是否偏离了自己的节奏”，再用 Safety Gate 决定普通行动是否适合，最后把状态转成一段由用户控制的求助表达。高风险时普通推荐会被系统阻断，数据不足时系统会先承认“不够了解”，而不是装作给出答案。

### 不建议使用的主张

| 不建议说 | 建议改成 |
|---|---|
| 我们比其他产品更懂你的心理 | 我们展示个人节奏变化和判断依据 |
| AI 心理医生 | 端侧状态观察与求助桥梁 |
| 诊断焦虑/抑郁 | 识别需要进一步关注的信号，不做诊断 |
| 证明某个练习有效 | 记录用户完成行动后的主观反馈 |
| 绝对保护隐私 | 本地优先、可导出、可删除；正式版还需加密存储 |
| 我们有独家的 Safety Gate | 我们把安全闸门做成可审计、可回归测试、不可被普通入口绕过的策略层 |

## 九、验证计划：把创新从概念变成证据

### 1. 用户验证 A07

沿用已有 `docs/匿名试用执行包.md`，建议把竞品差异化验证加入任务：

1. 用户完成一次低负担记录。
2. 用户回答“你觉得这个分数/状态是怎么来的”。
3. 用户指出当前可以做的行动和暂时不建议的行动。
4. 用户在普通波动和高风险两种演示情境下找到不同的下一步。
5. 用户生成一段发给朋友或老师的求助草稿，并指出哪些信息仍留在本机。

建议记录：完成率、理解正确率、完成任务所需时间、主观负担、对推荐的信任度、是否愿意在真实压力时使用。结果回填前不得写成“已证明有效”。

### 2. 专业审核 A08

沿用已有 `docs/专业审核执行包.md`，重点请审核者检查：

- 高风险关键词、否定语境和边界文案。
- Safety Gate 是否在所有入口优先于普通行动。
- “恢复指数”“风险”等词是否可能造成诊断误解。
- 求助草稿是否会产生责备、恐吓或过度承诺。
- 校内资源、热线和紧急服务的地区与时效标注。
- 漂流瓶/同伴支持未来上线时的审核、举报、危机升级和未成年人保护。

### 3. 竞品任务对照

不要只比较功能数量，建议用同一组任务比较：

| 任务 | 普通记录产品 | AI/内容产品 | 服务平台 | MindPulse 目标 |
|---|---|---|---|---|
| 记录今天状态 | 速度、负担、可回顾性 | 对话是否自然 | 通常不是核心 | 记录 + 数据来源 |
| 发现变化 | 图表/相关性 | 对话反思 | 专业评估 | 个人基线偏移 |
| 选择下一步 | 习惯或内容推荐 | AI 建议 | 转介 | 允许/阻断策略 |
| 遇到高风险 | 需查看各产品边界 | 危机转介/免责声明 | 联系专业人员 | 普通行动强制阻断 |
| 第一次求助 | 通常离开产品另找人 | 继续对话或转介 | 直接进入服务 | 生成可编辑求助草稿 |

### 4. 建议的验收目标

以下是后续测试目标，不是当前已取得的结果：

- 100% 的高风险回归用例不能出现普通轻干预主按钮。
- 100% 的数据不足回归用例不能出现假装精确的个人趋势结论。
- 至少 80% 的试用者能说明一次判断的主要依据和下一步。
- 至少 80% 的试用者能区分“偏离个人基线”和“高风险求助”。
- 试用者能明确知道求助正文不会在未主动复制/发送前离开本机。

## 十、风险与可持续壁垒

### 1. 主要风险

- **误报与漏报**：关键词策略不等于危机检测系统，必须持续做专业审核、边界提示和真实资源转介。
- **分数误解**：RISE 过于像医学量表会带来误导，应持续使用“状态观察指标”和解释性语言。
- **隐私过度承诺**：localStorage 适合原型，不足以支撑生产级安全承诺。
- **资源失效**：校园联系人、热线和服务时间会变化，需要来源、地区和最近核验时间。
- **社区治理**：本机漂流瓶不能包装成真实社区；上线多用户互动前需要独立治理方案。
- **证据不足**：规则通过和合成数据只能证明工程链路，不能替代用户研究、专业审核或临床研究。

### 2. 真正可能形成的壁垒

功能很容易被复制，MindPulse 的长期壁垒应来自：

1. 可解释、可回归测试的安全策略和边界样本库。
2. 用户持续积累的个人基线和行动反馈，但数据始终由用户控制。
3. 校园资源、话术和转接流程的真实验证与维护机制。
4. 专业审核、用户研究和版本化证据，而不是只展示漂亮页面。
5. “不确定时收敛、危险时阻断、需要时转给真人”的可信产品习惯。

## 十一、最终战略判断

MindPulse 最值得押注的不是“做一个功能更多的心理健康 App”，而是成为一个更窄、更可信的产品层：

> 用个人基线和低负担信号帮助大学生看见变化，用安全策略决定下一步，用最小披露的求助表达把人连接到真实支持。

因此，产品路线的优先级应是：

1. 把 Safety Gate、数据不足收敛、Reason Code 和允许/阻断动作做成稳定的核心引擎。
2. 把现有求助表达升级为校园 Warm Handoff，补齐资源配置和分享预览。
3. 把 RISE 从一个分数升级为“个人节奏观察”，严格控制诊断误解。
4. 把本地优先升级为可验证的最小披露、加密存储和用户控制权。
5. 通过 A07 和 A08 验证“用户是否理解、是否愿意使用、专业人员是否认可边界”，再决定是否扩展 AI、社区或校园群体服务。
