# 规则测试说明

本目录用于证明恢复指数、风险分级和推荐路径可以脱离页面单独检查。

当前包含：

- `tests/rule-cases.json`：规则测试样例。
- `src/rules/recovery-score.js`：恢复指数计算模块。
- `src/rules/risk-assessment.js`：风险分级模块。
- `src/rules/recommendation.js`：推荐路径模块。
- `src/rules/personalization.js`：个人基线偏移与推荐反馈自适应模块。

## 重点测试结论

| 编号 | 测试重点 | 预期 |
|---|---|---|
| R01 | 焦虑状态 | 推荐呼吸、散步、记录 |
| R02 | 低落状态 | 推荐呼吸、联系朋友、睡前放松 |
| R03 | 疲惫状态 | 推荐睡前放松、呼吸、小任务 |
| R04 | 出现“绝望” | 触发高风险，只返回求助入口 |
| R05 | 出现自伤相关表达 | 触发高风险，只返回求助入口 |
| R06 | 状态稳定 | 推荐小任务、记录、散步 |
| R07 | 安全短语误判控制 | “不想活在焦虑里”不直接触发高风险 |
| R08 | 危机表达变体 | “想从这个世界上消失”触发高风险 |
| R09 | 连续低睡眠 | 中度关注，优先睡眠、呼吸、记录 |
| R10 | 空文本 | 保持稳定观察，不误报 |
| R11 | 睡眠边界值 | 6 小时不算低睡眠连续触发 |
| R12 | 社交连接偏低 | 联系他人前置 |
| R13 | 明显低睡眠 | 保持三步路径，不推荐强专注 |
| R14 | 孤立表达 | “没有人在乎/留不住”进入求助入口 |
| R15 | 否定自伤误判控制 | “没有伤害自己的想法”不直接触发高风险 |
| R16 | 安全短语加真实危机 | 安全短语不会掩盖“想死”等明确危机词 |
| R17 | 连续社交断联 | 不医学化升级，但把联系他人前置 |
| R18 | 连续负面状态 | 中度关注，仍不伪装成诊断 |
| P01 | 个人基线偏移 | 睡眠、活动等明显低于个人历史时标记“明显偏离” |
| P02 | 推荐反馈自适应 | 过去完成后提升更明显的干预会被前置 |

国赛答辩时可说明：MindPulse-RISE 不只看固定分数，也看当前匿名档案的个人基线偏移；Safety Gate 的心理安全优先级高于普通推荐逻辑，高风险触发后不会继续安排普通自助干预作为主路径。
